# 运维与排障

把日常巡检和排障常用的那些命令，做成看一眼就懂的视图：体检、漂移、日志、端口、进程、服务、磁盘、连通性，以及多机批量。

![主机体检与问题清单](../assets/ops.png)

## 能做什么

- **主机体检**：一次采集 CPU / 内存 / 负载 / 磁盘 / 网络 / 关键服务，解析成档案并标出问题项。
- **与上次比（配置漂移）**：同一台机器的两次体检结果对比，谁改了配置、多了端口一目了然。
- **变更快照**：AI 做写操作前自动拍快照，回合结束再拍一次，有变化就出报告（可回滚参考）。
- **日志**：
  - 单机 tail（可跟随）；
  - 多主机日志合流到一个流里看；
  - 历史检索（含 `.gz` 轮转文件）；
  - 日志洞察：同类错误归并、时间分布、异常点。
- **端口**：监听端口列表（进程、地址、协议），可疑端口一眼看到。
- **进程**：按 CPU / 内存排序，看命令行与所属用户，可结束进程（需授权）。
- **服务**：systemd 服务状态、启停、开机自启、查看最近日志。
- **磁盘**：分区占用、大目录分析（哪一层占了多少）。
- **连通性探测**：从本机或多台主机向目标（`host:port` / URL / 域名）探活，结果汇总成表。
- **拓扑**：按主机分组和连接关系画一张简单的拓扑图。
- **部署评审**：把要上线的命令 / 配置先过一遍，标出风险点再执行。
- **批量执行**：一次在多台主机上跑同一条命令，汇总输出、区分成功失败；支持分批（金丝雀 / 滚动）。
- **主机仪表盘**：CPU / 内存 / 网络 / 磁盘 IO 实时曲线。
- **趋势**：关键指标按时间留存，看长期变化。

## 怎么用

1. **例行体检**：选中主机分组 → 体检 → 看问题项；下次再体检就自动有"和上次比"。
2. **排障**：先看仪表盘和端口，再看日志（必要时多机合流），最后让 AI 结合上下文分析。
3. **改配置前**：先部署评审，确认风险点，再执行；执行后看变更快照。
4. **多机操作**：批量执行 + 分批，先小范围验证再全量。

## 注意

- 只读操作（看日志、看端口、看进程）不需要授权；结束进程、启停服务、改配置要授权并留执行记录。
- 多机批量执行属于高风险操作，建议先用一台验证命令。
