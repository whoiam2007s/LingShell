# Git

不用离开灵壳就能看改动、暂存、提交、切分支；提交说明可以让 AI 按实际 diff 写，冲突也有 AI 解释。

![Git 改动列表与文件 diff](../assets/git.png)

## 能做什么

- **仓库识别**：打开任意目录，自动找到所属仓库与当前分支。
- **改动列表**：未跟踪 / 未暂存 / 已暂存分列；子目录也能定位到仓库根。
- **差异查看**：逐文件看 diff，未跟踪文件也能看内容差异。
- **暂存 / 取消暂存**：按文件操作，不必记 `git add -p`。
- **提交**：写提交说明并提交；提交前能看到将要提交的内容。
- **AI 提交说明**：根据实际 diff 生成规范化的提交信息（可编辑后再提交）。
- **分支**：查看、新建、切换、删除；分支列表带最近提交。
- **合并 / rebase**：发起合并、处理冲突；冲突文件列表 + 双方标记的 diff。
- **stash**：暂存改动、恢复、查看列表。
- **历史**：提交历史浏览，看某次提交改了什么。
- **blame**：逐行看是谁、哪次提交改的。
- **比较**：分支间 / 提交间比较差异。
- **远程**：查看远程地址、拉取、推送（走系统 git 配置与凭据）。

## 怎么用

1. 在资源管理器里打开仓库目录，切到 Git 面板。
2. 看改动 → 选要提交的文件 → 暂存。
3. 点"AI 写提交说明"，检查后提交。
4. 需要换分支时在分支列表里切；改动没提交会提示先 stash。

## 注意

- 用的是本机已经装好的 `git`，凭据和 hooks 都按你现有配置走。
- 涉及 `.git/hooks` 的仓库，提交前钩子会照常执行。
- 合并 / rebase 属于改写历史的操作，AI 不会自动做，需要你在面板里确认。
