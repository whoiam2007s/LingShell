# 自动化与巡检

把"每天要看的东西"变成定时任务，出问题主动通知你；把做过的一次操作沉淀成可复用的手册。

![定时巡检与告警推送](../assets/automation.png)

## 能做什么

- **定时巡检**：按 cron 定时跑一组检查（主机体检、磁盘、日志关键字、服务状态等），结果留档，异常才提醒。
- **看门狗**：用自然语言写报警条件（例如"磁盘超过 85% 或者 nginx 挂了就告诉我"），AI 定时判断，命中即告警。
- **证书与域名巡检**：检查证书到期时间、域名解析与连通性，可选"从本机检查"或"从某台主机检查"（内网站点）。
- **基线合规**：定义一组基线规则（如 SSH 配置、密码策略、危险端口），批量检查主机并给出不符合项。
- **告警推送**：钉钉 / 飞书 / 企业微信群机器人，巡检、看门狗、证书到期、部署结果都能推。
- **快速命令**：把常用命令存成按钮组（全局 / 分组 / 主机），底部一点即发；也可让 AI 生成一组。
- **运维手册（runbook）**：把多步操作（含检查项和改动项）沉淀成带参数的步骤，下次照着手册执行；可以从执行记录一键整理成手册。
- **模板**：常用命令 / 脚本模板，复用同一套骨架。
- **自动应答**：终端出现特定提示（如 `password:`、`[y/N]`）时自动回复预设内容，减少交互卡顿。

## 怎么用

1. **先手动跑通**：把一次巡检 / 排障过程在对话或终端里走通。
2. **存成手册或快速命令**：满意后让 AI 把它整理成 runbook（会提示把主机、路径等提成参数）。
3. **设定时**：在「定时巡检」里选检查项、频率、目标主机分组和推送渠道。
4. **配看门狗**：用一句话描述报警条件，选检查频率。
5. **收告警**：群机器人收到消息后可以点进来，让 AI 接着排查。

## 注意

- 巡检默认只读；需要写操作的步骤要单独授权，不会静默执行。
- 定时任务依赖本机在跑（灵壳是本地优先的桌面应用），电脑关机时不会执行。
- 推送内容会带主机名与摘要，注意群机器人的可见范围。
